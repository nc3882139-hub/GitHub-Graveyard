## 🧟 About The Project

**GitHub Graveyard** is a hauntingly beautiful web application that tracks, visualizes, and even resurrects deleted code from your GitHub repositories. Every time you delete code, it doesn't just disappear—it becomes part of an interactive 3D graveyard where lines of code float like restless spirits, waiting for their chance to rise again.

### 🎯 The Problem

Developers delete thousands of lines of code every day. Most of it is lost forever, never to be seen again. But what if we could:
- Visualize what we've deleted?
- Understand our deletion patterns?
- Even bring back code from the dead?

### 💡 The Solution

**GitHub Graveyard** transforms deleted code into an immersive experience:
- 👻 **3D Visualization**: Deleted code floats as ghostly text in a three-dimensional space
- 📊 **Deletion Analytics**: Track your deletion habits with beautiful statistics
- ⚡ **Code Resurrection**: Bring back deleted code from the last 24 hours with one click
- 🔔 **Real-time Updates**: Every push triggers the graveyard to update instantly

## ✨ Features

### 👻 Ghost Visualization
- **3D Floating Text**: Deleted lines of code float in space like restless spirits
- **Glow Effects**: Each ghost has an ethereal green glow
- **Particle System**: Ambient particles create a haunting atmosphere
- **Interactive Camera**: Rotate and zoom around the graveyard

### 📊 Deletion Analytics
- **Total Deletions Counter**: Watch your deletion count grow
- **Files Affected**: See which files are being haunted
- **Last Deletion Timestamp**: Know when the graveyard last claimed code
- **Deletion History**: Detailed list of all deleted code with commit messages

### ⚡ Resurrection Engine
- **24-Hour Window**: Only code deleted in the last 24 hours can rise again
- **One-Click Restore**: Instantly resurrect deleted lines
- **Detailed Reports**: See exactly what was brought back
- **File Tracking**: Know which files were affected by the resurrection

### 🔔 Webhook Integration
- **Real-time Updates**: Graveyard updates instantly on every push
- **Commit Tracking**: See exactly which commits deleted what
- **Author Attribution**: Know who killed the code

### 🎨 UI/UX Features
- **Dark Theme**: Perfect for late-night coding sessions
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Smooth Animations**: Every interaction feels polished
- **Interactive 3D**: Rotate and explore the graveyard
